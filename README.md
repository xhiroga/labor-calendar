# labor-calendar

働き方の条件を選ぶと、所得税・住民税・労働保険・社会保険のお金と書類の流れを12か月のシーケンス図で示すページです。

https://labor-calendar.hiroga.workers.dev/

金額は概算です。計算の前提と出典はページ下部の「計算の前提と出典」にあります。実際の手続きは税理士、社労士、窓口で確認してください。

## URL の書き方

条件はクエリパラメータ、図の月の行はアンカーで指せます。

```
https://labor-calendar.hiroga.workers.dev/?<条件>#<節>-<年>-<月>
```

例:

| URL | 開く場所 |
|---|---|
| [`?work=contractor&src=2#tax-next-01`](https://labor-calendar.hiroga.workers.dev/?work=contractor&src=2#tax-next-01) | 士業への報酬。翌年1月の徴収高計算書と支払調書 |
| [`?work=officer&start=7&amt=100000#soc-current-08`](https://labor-calendar.hiroga.workers.dev/?work=officer&start=7&amt=100000#soc-current-08) | 7月に就任した役員。8月の社会保険料の納付 |
| [`#lab-current-07`](https://labor-calendar.hiroga.workers.dev/#lab-current-07) | 既定の条件 (無期雇用)。7月の年度更新 |

### 条件

画面で条件を変えると URL も変わるので、開いている画面の URL をそのまま渡せます。既定値と同じ項目は URL に出ません。

| パラメータ | 値 (先頭が既定値) | 意味 | 使う働き方 |
|---|---|---|---|
| `work` | `permanent` / `fixed` / `contractor` / `officer` | 無期雇用 / 有期雇用 / 業務委託 / 役員 | すべて |
| `start` | `0` / `1`〜`12` | 前年以前から / 今年の開始月 | すべて |
| `end` | `0` / `1`〜`12` | 終了なし / 今年の終了月 (月末) | すべて |
| `amt` | `300000` (`0`〜`2000000`) | 月額 (円) | すべて |
| `age` | `0` / `1` | 40歳未満 / 40〜64歳 | すべて |
| `toku` | `1` / `0` | 源泉所得税の納期特例: 承認済み / 未承認 | すべて (業務委託は士業だけ) |
| `big` | `0` / `1` | 従業員数: 50人以下 / 51人以上 | 雇用 |
| `hours` | `30` / `20` / `0` | 週の所定労働時間: 30時間以上 / 20〜30時間 / 20時間未満 | 雇用 |
| `jt` | `1` / `0` | 住民税の納期特例: 承認済み / 未承認 | 雇用、役員 |
| `cur` | `0` / `1` | 給与の支払い: 翌月払い / 当月払い | 雇用、役員 |
| `fil` | `0` / `1` | 年末調整のあとの確定申告: しない / する | 雇用、役員 |
| `tk` | `0` / `1` | 労災保険の特別加入: しない / する | 役員、業務委託 |
| `exp` | `20` (`0`〜`90`) | 経費 (売上に対する %) | 業務委託 |
| `src` | `1` / `2` / `0` | 報酬の種類: 源泉徴収の対象 / 士業 / 対象外 | 業務委託 |
| `vat` | `0` / `1` | 消費税の申告: しない / する | 業務委託 |
| `lab` | 雇用: `both` / `rosai`、役員: `officerNone` / `tokubetsu1`、業務委託: `none` / `tokubetsu` | 労働保険のタブ。省くと条件に合うタブを開く | すべて |

### アンカー

`#<節>-<年>-<月>` の形で、開くとその月の行へ移って枠で示します。

| 部分 | 値 |
|---|---|
| 節 | `tax` (所得税・住民税) / `soc` (社会保険) / `lab` (労働保険) |
| 年 | `current` (今年) / `next` (翌年) |
| 月 | `01`〜`12` |

図に行がなければ、移動せずページの先頭で開きます。翌年は作業のある月の行だけで、労働保険の支払いがない条件には `lab` の行がありません。

## 開発

`public/index.html` をブラウザで開くと動きます。ビルドは要りません。Cloudflare Workers の静的配信で公開します (`npx wrangler deploy`)。
